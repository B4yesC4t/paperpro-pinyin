# 语音输入

按住空格说话，松开后文字出现在光标处。录音来自蓝牙麦克风，识别用 DeepSeek 语音识别，
再由 DeepSeek Flash 整理成便于回看的笔记（可关闭）：修正错别字、同音字和标点，按主题分段，
内容多时加小标题和列表，保留原意、口吻和所有有效信息。

## 需要什么

- **支持免提通话（HFP）的蓝牙麦克风或耳机**。已测试：DJI Mic Mini（发射器直连）。
  大多数能用来打电话的蓝牙耳机都支持 HFP。只能听音乐的设备、或要插 USB 接收器的
  “无线麦克风”不行（平板没有 USB 音频支持）。
- **DeepSeek API Key**：在 <https://platform.deepseek.com> 创建。语音识别按音频时长计费
  （官方价格约 0.78 元/小时，限时 0.39 元/小时），Flash 整理按字数计费，日常使用花费很少。
- 平板连着 Wi-Fi。

## 设置

在笔记本的文字模式里打开屏幕键盘，点最下面一排的 **⚙** 打开“输入法设置”。
（使用 Type Folio 时，语音还没配置好的情况下按住空格，也会打开设置页。）

1. **打开蓝牙**。reMarkable 系统里没有蓝牙开关，这里的开关会载入平板自带的蓝牙驱动。
   打开后会保持，重启后自动恢复。
2. **配对麦克风**：把麦克风切到配对模式（通常是长按电源键或配对键，直到指示灯快速闪烁），
   点“搜索设备”，在列表里点它旁边的“配对”。第一个配对的音频设备会自动选为麦克风。
3. **填写 API Key**：点“填写”，输入 Key 后点“保存”，会自动测试连接。
   Key 只保存在平板上（`/home/root/paperpro-pinyin/user/deepseek-key`，仅 root 可读），
   不会进入安装包，升级时保留。
4. **Flash 优化**（可选）：默认开启。默认提示词把口述整理成笔记，可以改成自己的
   （“恢复默认”随时改回）；没改过提示词的人，升级后自动用上新的默认提示词。
   在“热词”里列出人名、产品名等专有名词（每行一个或用逗号隔开），优化时会优先采用这些写法。

编辑提示词和热词时，可以照常用拼音输入法。

## 使用

| | 外接键盘（Type Folio） | 屏幕键盘 |
| --- | --- | --- |
| 说话 | **按住空格**说话，松开结束 | 同样可以**长按空格**；或点 **🎤** 开始，说完再点一次 |
| 取消 | **Esc** | — |
| 打开设置 | 语音没配置好时按住空格 | 点 **⚙** |

说话时，光标处显示“● 正在听 0:05”，松开后依次显示“识别中…”“整理中…”，
然后文字插入光标处。正在打的拼音会先按第一个候选上屏。单次最长约 110 秒。

短按空格仍是普通的空格（打拼音时是上屏第一个候选），只是在松开时才生效。

进入文字模式时，平板会在后台先连好麦克风（约 3 秒），所以按下空格就能开始说话；
离开文字模式 5 分钟后断开，省电。

## 隐私

拼音输入完全在平板本地运行。**语音输入需要联网**：录音会上传到 DeepSeek 做识别；
开启 Flash 优化时，识别出的文字会再发给 DeepSeek 整理。不使用语音输入时，
不会有任何内容离开平板。

## 常见问题

**提示“麦克风拒绝了连接，可能正连着其他设备”**
麦克风同一时间通常只连一个设备。断开手机、电脑或它自己的接收器，再试一次。

**提示“连不上麦克风”**
确认麦克风已开机、在平板附近。必要时在设置页“忘记”后重新配对。

**提示“这个麦克风没有免提服务（HFP）”**
这个设备不支持免提通话，不能用作语音输入。

**识别结果里专有名词总是写错**
把它们加进设置页的“热词”。

**不想让 Flash 改动文字**
在设置页关闭“用 Flash 优化”，就直接使用识别结果。

**只想改错字，不想分段、加标题**
把优化提示词改成只修正同音字、错字和标点的版本，例如：
“修正语音转写中的同音字、明显错字和标点，不改变原意，不总结，也不回答转写中的问题。”

## 工作原理（简述）

平板的内核里有蓝牙的 L2CAP 与 SCO，但没有免提协议所需的 RFCOMM。`voice-hfp` 程序在
用户态实现了 RFCOMM（TS 07.10 的子集，按信用量流控）和免提协议的音频网关一侧：
平板扮演“手机”，回应麦克风的 AT 指令建立服务级连接，需要录音时打开 SCO 语音链路，
读取 8 kHz、16 位的窄带语音。连接建立后会禁止该链路进入 Sniff 省电模式：
实测 DJI Mic Mini 在 Sniff 下无法退出，会导致语音链路建立超时、连接断开。

录好的音频封装成 WAV 上传到 `https://api.deepseek.com/v1/tools/asr`；整理用
`deepseek-flash` 模型（`reasoning_effort: low`），失败或 30 秒内没有返回时直接使用识别结果。
